# 启动台整理 · Launchpad Tidy

一个用 SwiftUI 开发的 macOS 原生启动台整理工具。基础整理无需联网或管理员密码；AI 整理调用用户配置的模型接口，也支持本机 Ollama。

## 构建与运行

```bash
git clone https://github.com/zlxamx/launchpad-tidy.git
cd launchpad-tidy
./scripts/build.sh
open 'dist/启动台整理.app'
```

需要 macOS 14 及以上和支持 Swift 5.10 的 Xcode 开发工具。当前生成的是本机架构的开发版本，使用本地临时签名，尚未经过 Apple 公证，不作为公开发行安装包。

也可以用 Xcode 打开 `Package.swift`，选择 LaunchpadTidy 运行。

## 使用

核心路径：**AI 整理 → 查看结果 → 应用**。首次使用填写 AI 配置，后续两次点击完成整理和应用。

- 默认窗口 680 × 500，最小 560 × 400；⇧⌘0 恢复紧凑尺寸。宽度小于 800 时用顶部菜单切换范围，拉宽后显示侧栏。
- 主界面保留搜索、AI 整理和应用网格。选择应用后显示“移动到”和“建文件夹”；也可直接拖到侧栏文件夹。页面列表默认收起，按需展开。
- 有改动时显示“应用”，点击后直接自动备份并写入，Dock 会短暂刷新，不再重复弹确认框。“N 项改动”可按需查看明细；⌘Z 撤销、⇧⌘Z 重做，预览仍自动保存。
- “更多”（右上角 ⋯）集中放置 AI 设置、本地分类、按名称排序、新建文件夹、页面管理、撤销／重做、放弃改动、备份恢复及重新读取。
- 单击多选，⇧ 点击连续选择，⌘A 全选当前结果，⌘F 搜索。搜索变化会取消筛选外的选择。双击打开应用，右键可显示文件位置或移动。
- 右键侧栏文件夹可重命名、排序或解散。解散时自动分配页面；清理空页保留至少一页。页面／文件夹内可拖动应用调整顺序。
- 本地分类仅处理当前范围内未归类的应用，已有选择时仅处理选择项。“按名称排序”在全部应用视图下整理整个布局，搜索期间禁用。
- 备份恢复先载入预览，再点击应用；应用注册清单或布局指纹不匹配时拒绝覆盖。自动备份、冲突检查、事务回滚和恢复能力均保留。

多选拖到侧栏会移动全部选择项；拖到另一个应用前只调整被拖动的一个应用。全局应用视图按名称展示，真实图标顺序请在页面／文件夹视图查看。页面视图汇总该页及其文件夹内的应用，属于管理列表，不是启动台像素级布局复刻。

参考 Apple 的[应用入口说明](https://support.apple.com/guide/mac-help/open-apps-in-spotlight-mh35840/mac)。启动台数据库是系统内部实现，没有公开的稳定编辑接口。本工具通过版本、结构和冲突检测控制写入，遇到不支持的结构或下载中的应用会拒绝整理。

## AI 整理

1. 首次点击“AI 整理”，或打开“更多 → AI 设置”。
2. 填写 Base URL、模型名称和 API Key。支持返回 Chat Completions JSON 的兼容接口；Base URL 可包含 `/v1`，软件自动拼接 `/chat/completions`，也可直接填写完整接口路径。
3. 内置 DeepSeek 和本机 Ollama 地址预设。可点击“检测连接”，检查认证并选择返回的模型，也可手动填写。检测使用 `/models`，不发送应用清单，不代表已完成模型推理测试。Ollama 默认地址为 `http://127.0.0.1:11434/v1`，通常不需要 Key；软件不会安装或启动 Ollama。
4. 默认整理全部可见应用，不受当前搜索、侧栏或选择项限制。勾选“仅整理未归类应用”后，已有分类继续保留。展开“更多选项”可以填写个人偏好，例如“写作相关放一起，开发工具单独分类，文件夹不要超过 8 个”。
5. 保存设置后，一键发起请求。等待期间可点击底部“取消”。结果经过完整性检查后进入预览，⌘Z 可整体撤销，再点击“应用”完成备份与写入。

AI 会优先复用同名文件夹，对新分类创建文件夹，并自动分页。只清理由本次移动变为空的旧文件夹，保留原本为空的文件夹。AI 标记为不确定的应用继续留在原容器；相邻应用被移走后，排序编号可能因补齐空位而改变。

API Key 按接口地址单独存入 macOS 钥匙串，不保存到配置文件。切换地址读取对应密钥；仅修改尾部斜杠等不会改变最终接口的格式时，保留已填密钥。非敏感配置保存在用户偏好中。只向填写的接口发送可见应用名称、应用标识、现有分类名和整理偏好；不发送应用文件、路径、数据库或书签。远程接口可能收费。远程地址要求 HTTPS，本机回环地址允许 HTTP，重定向不会被自动跟随。

接口需要支持非流式 `/chat/completions`。默认启用 `response_format: {"type":"json_object"}`；不支持此选项时可在“更多选项”关闭 JSON 模式，软件仍会严格检查 JSON 内容，并兼容包裹 JSON 的代码围栏。软件校验每个输入应用恰好出现一次，拒绝未知 ID、重复、遗漏、无效名称和截断回复；失败或取消时保留现有预览。参考 [DeepSeek Chat Completions 文档](https://api-docs.deepseek.com/api/create-chat-completion/)和 [Ollama 兼容接口文档](https://docs.ollama.com/api/openai-compatibility)。

## 数据与恢复边界

- 不移动、卸载或删除任何 `.app` 文件，不修改系统内部 Holding Page 中的隐藏应用。
- 仅管理可见应用位置、顺序、文件夹名称及布局容器。预览自动保存在 `~/Library/Application Support/LaunchpadTidy/PendingDraft.json`，文件权限为 600，不包含应用书签和凭证。应用、撤销到原布局或明确放弃预览后清除；冲突的旧预览在后续编辑前改名保留。
- 备份位于 `~/Library/Application Support/LaunchpadTidy/Backups/`，是通过 SQLite backup API 创建的完整一致性快照，转换为无需 WAL 附件的独立数据库，并限制为当前用户可读写。
- 布局在编辑期间发生变化会拒绝应用，必须重新读取。不提供忽略冲突强制覆盖。
- 文件夹批量移动和跨页排序自动分为每页最多 16 个应用。主页面容量按 35 与原布局观测最大值中较大者检查；普通批量移动超额时立即拒绝，保留选择和原预览，需另选页面。解散文件夹自动分配页面。自定义启动台行列网格尚未精确适配。
- 写入失败回滚事务，恢复 Dock；单独的 20 秒看护进程在软件意外退出时恢复暂停的 Dock，写入流程设有更短的提交期限。
- 不支持跨设备布局导入，备份恢复也要求应用注册清单一致。

## 验证

```bash
swift test
```

测试使用临时数据库，覆盖系统排序／删除触发器、批量移动、文件夹分页、解散、排序、新建、重命名、冲突拒绝、事务回滚、WAL 备份和恢复，以及模拟 AI 接口请求、响应校验、取消、AI 方案布局生成和写入／恢复。可额外用准备好的独立数据库副本验证真实结构：

```bash
LAUNCHPAD_TEST_DATABASE='/absolute/path/to/standalone-copy.sqlite' swift test
```

测试只操作新建的临时副本，不能将线上数据库作为写入测试目标。真实结构测试会再复制输入文件，因此输入应为通过 SQLite backup API 生成并设置 `PRAGMA journal_mode=DELETE` 的独立快照，不要直接拷贝运行中的 WAL 数据库文件。

软件还提供只读诊断命令，输出系统版本、可见应用数量、页面数量、文件夹数量和布局指纹：

```bash
'dist/启动台整理.app/Contents/MacOS/LaunchpadTidy' --inspect
```

开发回归已通过 29 项测试，包含独立的真实数据库副本。模拟接口和副本测试不能替代具体 AI 服务联调、macOS 15 实机验证及重启后的验收；不同系统环境仍需自行验证。
